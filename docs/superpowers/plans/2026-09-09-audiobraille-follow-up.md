# AudioBraille 后续任务交接：训练输入、体验听书与播放高亮

日期：2026-09-09
状态：需求确认与实现计划，尚未开始本轮代码修改。

## 用户确认的问题

1. 正式实验统一训练的流程已经能按“完整规则 → 六个单点 → 多点示例 → 不计分练习 → 固定校准”播放并自动推进；但训练页面目前主要是文案/静态提示，没有像正式辨识一样显示真实的盲文输入面板。需要让训练阶段有可操作的小键盘输入显示。
2. “体验听书”应与首页的“学习盲文”“AudioBraille 实验”“笔记”并列，作为不进入正式研究流程的独立体验入口。正式实验中的听书仍保留为正式流程的一环，并继续在完成训练、校准和四类辨识后开放。
3. 体验听书内容可以更长：提供若干书籍/章节选择，并同时展示明文与盲文对应内容，方便对照阅读和体验 AudioBraille 播放。
4. AudioBraille 播放时，当前正在播放的盲文方应高亮。该能力最好抽成全局可复用机制，应用到教学、训练/实验展示、听书、笔记等所有展示盲文方的地方；原生 textarea 本身无法逐方高亮，需要配套的只读/对照预览层，不破坏 textarea 编辑能力。

## 下一轮实施顺序

### A. 训练输入面板

1. 把正式辨识使用的 `inputDisplayHtml(...)` 抽成可复用训练输入渲染；训练页显示已确认方、当前点位、光标/组边界和小键盘提示。
2. 练习和校准：播放后开放输入，按 `0` 提交；练习只反馈熟悉用途、不计入正式结果；校准按固定答案自动判定，仍需 2/3 通过。
3. 单点、多点示例：显示当前示例方及输入区域/提示，明确它们是示范阶段而非正式答题；不能因为加入显示而破坏自动顺序播放。
4. 加 DOM/纯逻辑测试：训练每一步存在真实输入显示；提交前播放限制仍有效；训练记录为 `training` 且不进入上传批次。

### B. 独立“体验听书”入口

1. 在 `app-state.js` 增加独立顶层页面（建议 id `reader` 或 `listen`，最终命名统一为“体验听书”），并接入 `TOP_LEVEL_PAGES`、顶部导航、首页入口、页面路由和切页时的输入/播放清理。
2. 将现有 casual 听书 UI 拆成独立体验页；formal reader 继续留在正式实验状态机中，只有完成训练/校准/辨识后开放。
3. 扩充/新增版本化书籍章节数据（稳定 id、版本、标题、明文、盲文方序列），至少覆盖多段较长章节；支持章节选择、明文/盲文对照、播放/暂停/停止/速度（体验模式可调）。正式材料不与体验材料混用。
4. 增加页面和状态测试，确保直接进入“体验听书”可用，而 formal 未完成时仍不能绕过正式阶段。

### C. 全局播放高亮

1. 在 AudioBraille 播放序列层提供 `onCellStart(index, cell)` / `onComplete` 或等效回调，确保逐方播放有稳定索引。
2. 在统一渲染层维护当前播放对象和高亮索引，播放开始时给对应盲文方加 `is-playing`，结束/停止/切页时清理。
3. 抽取通用盲文方渲染组件/HTML builder，用 `data-cell-index` 和 `aria-current` 标识当前方；覆盖教学参考、训练示例、实验展示、听书盲文对照、笔记朗读参考。
4. 对 textarea 保留原生编辑和光标，只在相邻对照视图高亮；不能用 DOM overlay 阻断 textarea 输入。
5. 增加高亮渲染、停止清理、播放序列回调和移动端布局测试。

### D. 验证与提交

- 每个子任务遵循：失败测试 → 最少实现 → 通过测试 → commit。
- 验证命令：`npx vitest run`、`npm run build`、各关键 `node --check`、`git diff --check`；补充 `Invoke-WebRequest`/Vite smoke。
- 完成 2~3 个子任务后按 `AGENTS.md` 派一个 fresh、只读 reviewer，逐项检查规格第 2 节盲文编码表，不执行命令、不写文件。
- 完成后更新 `AGENTS.md` 当前进度，再按规则提交。

## 浏览器测试工具确认

用户已确认可以使用 `@浏览器`（Codex In-app Browser）协助测试。后续浏览器验证优先使用 `mcp__cua_repl`：先检查/打开浏览器标签页，再按真实键盘和按钮操作，并用无障碍树或截图确认结果。Playwright CLI 不再作为唯一浏览器验证手段；Vitest、`node --check`、Vite HTTP smoke 仍是可重复验证的主体。

本轮浏览器验证曾确认：启动门按 `0`、进入正式实验、同意、背景资料和统一训练页面均可到达；规则播放完成后会进入六个单点，单点完成后进入多点，多点完成后进入不计分练习。已发现并记录的待修复体验问题是训练页缺少正式实验同款的真实输入显示。
