# AudioBraille v11：textarea 单一盲文文档视图

日期：2026-08-27
状态：设计已确认，待实现

## 1. 目标

将笔记编辑区改为单一文档视图：`#note-textarea` 同时承担盲文文档显示和原生光标显示。

当前自定义 `.document-display` 与 textarea 显示同一份内容，造成重复布局、光标不在真实编辑位置和视觉层级混乱。v11 删除自定义文档显示区，只保留 textarea。

## 2. 目标布局

```text
上方：当前多方输入区
      六点实时反馈，保留方框，帮助用户组成当前声母/韵母/声调组合

下方：#note-textarea
      连续 Unicode 盲文文档
      使用 textarea 原生光标
      支持回车换行、自动软换行和垂直滚动
```

上方区域是输入辅助，不是最终文档展示，因此保留当前输入方的六点反馈和方框。下方文档不再显示盲文方块、边框或额外的自定义光标。

## 3. 光标行为

文档状态继续保留“已确认输入单元数组 + 文档光标”：

```js
{
  documentCells: [
    [[1, 2, 4, 5]],
    [[1, 4]],
    null,
    { kind: 'text', value: '\\n' }
  ],
  documentCursor: 2
}
```

`documentCursor` 表示文档单元之间的位置。每次 `/`、`*`、`3` 或小键盘输入改变文档状态后：

1. 将 `documentCells` 转换为 textarea 的连续文本。
2. 将文档单元边界转换为文本偏移量。
3. 设置：

```js
textarea.selectionStart = offset
textarea.selectionEnd = offset
```

4. 如果 textarea 原本处于编辑焦点，保留焦点并恢复原生光标；小键盘操作导致页面重渲染时，重新聚焦当前 textarea 并恢复偏移量。

对于一个包含多个盲文方的已确认输入单元，光标只停在该多方单元的前后边界，不在其内部显示文档光标。当前多方内部的 `/`、`*` 仍由上方组合区处理。

## 4. 按键规则

### 当前多方非空

- 点位键：更新上方当前方。
- `*`：确认当前方并在上方多方组合中向右移动。
- `/`：在上方多方组合中向左移动；当前方有点时先清当前方。
- `0`：把上方完整组合整体插入 textarea 文档，并将原生光标置于插入单元之后。
- `3`：当前方有点时清当前方；当前方为空时删除上方组合中光标左侧的一个方。

### 当前多方为空

- `/`：textarea 文档光标向左移动一个已确认输入单元。
- `*`：textarea 文档光标向右移动一个已确认输入单元。
- `3`：删除 textarea 文档光标左侧的一个已确认输入单元，并将光标左移。
- `.`：在 textarea 文档光标处插入空格单元。

文档编辑仍然按已确认输入单元处理，不判断拼音、音节或普通话合法性。

## 5. 回车与自动换行

- textarea 设置 `wrap="soft"`，长盲文内容在控件宽度内自动换行。
- 用户按 Enter 时使用 textarea 原生行为，插入真实换行符 `\\n`。
- 换行符作为普通文本 atom 保存，不转换成盲文方，不触发拼音解析。
- 重新渲染后保留换行符和文本内容。
- CSS 不使用水平溢出隐藏来伪造换行；textarea 允许自然垂直滚动。

## 6. 直接编辑

笔记 textarea 继续允许鼠标和普通键盘直接编辑：

- `input` 事件读取 textarea 当前值。
- 重新建立文档单元数组，盲文 Unicode 字符各自成为单方输入单元；普通空格成为空格单元；换行和其他文字成为文本单元。
- 直接编辑后文档光标移动到 textarea 文本末尾，避免把浏览器字符偏移错误解释为多方边界。
- 小键盘编辑时，textarea 由应用状态回写并恢复原生光标。

## 8. 测试验收

1. 笔记页只存在一个盲文文档显示控件：`#note-textarea`，不存在 `.document-display`。
2. 输入 `t`、按 `0` 后，上方回到空当前方，textarea 显示 `⠞`，原生光标位于末尾。
3. 再输入 `c`、按 `0` 后，textarea 显示 `⠞⠉`，上方仍只有一个当前方。
4. 按 `/` 后，textarea 原生光标位于 `⠞` 和 `⠉` 之间。
5. 按 `3` 后，textarea 只剩 `⠉`，原生光标位于开头。
6. 在两个单元之间输入新的盲文方后，新内容插入中间，不覆盖右侧内容。
7. 按 `.` 后插入普通空格，textarea 自动显示空格。
8. textarea 按 Enter 后产生 `\\n`，再次渲染后换行仍存在。
9. 长文本在 textarea 内自动折行，不产生文档方块或水平溢出。
10. 当前多方组合期间，上方六点反馈继续显示；下方不再显示第二个自定义光标。
11. 原有教学、实验答题、拼音对照、保存和导出测试继续通过。
12. `npx vitest run` 和 `npm run build` 成功。
