## 1. 产品定位（用户确认）

> **"为明眼人设计的、盲人友好的教学、输入、新方法听盲文的一个整合平台"**

- 主要用户：想学盲文的明眼人 + 盲人
- 核心功能：①学习（中文拼音/英文/符号/数字）②输入（在线测试 + 笔记）③新功能测试（AudioBraille 音频辨识）④听书
- 原则：盲人友好 ≠ 无文字。保留文字提示（明眼人可见 + 屏幕阅读器可读），TTS 辅助

## 2. 权威盲文编码（不变，来自 v2 规格第 2 节 + 本次查证）

**本次网络查证确认（GB/T 15720-2008 + 国家通用盲文方案 2018）**：

- 现行盲文 = 声母方 + 韵母方 + 声调方（**三方表示一个完整音节**）
- 声调：阴平=点1、阳平=点2、上声=点3、**去声=点23**、轻声不标调
- **国家通用盲文**（2018 实施）：字字标调 + 按声母省写部分调号；是现行盲文的"升级版"
- 教学采用**全标调**（国家通用盲文思路），符合用户选择

**TTS 读拼音问题**：TTS 无法正确朗读拼音字母（"ba"读成 B A）。**决策：不读拼音本身，读标调名**——"声母 m，韵母 a，阴平"。宁缺毋滥。

## 3. 页面架构（用户确认的流程）

进入页面

       └─ 首页三个功能入口（+听书）
            ├─ ① 学习
            │    ├─ 中文拼音（全标调）
            │    ├─ 英文 26 字母

            │    └─ 笔记记录器（明文对照 + 导出 + 朗读）
            ├─ ③ 新功能测试（AudioBraille 音频辨识）

## 4. 数字小键盘键位（用户确认）

| 键 | 功能 |
|---|---|
| 7/4/1/8/5/2 | 点1~6（按下即亮，**顺序无关**：178=781=187=871 等效）|
| **0** | 提交/确认（教学判定、测试提交、输入上屏）|
| **`*`** | **下一个**（拼音：声母→韵母→声调；输入：光标右移）|
| **`/`** | **上一个**（拼音：回上一阶段；输入：光标左移）|
| 3 | 退格 |
| . | 空格 |
| - | 清空（保留现状）|
| + | 朗读当前点位/重听音频（保留现状）|

**输入边界设计（解决用户提出的 178781 拆分问题）**：
- 输入是**逐方确认**的：按 7,1,8 组成一方 → 按 `*` 进入下一方 → 按 7,8 组成韵母 → 按 `*` → 按 1 声调 → 按 0 提交
- 边界永远清晰，**不存在连串歧义**（不会出现 178781 无法拆解的情况）
- 点位集合顺序无关：无论按 7,1,8 还是 8,1,7，都表示同一方

## 5. 学习模块（四子模块，学→练→考 三阶段）

**用户反馈：三阶段逻辑值得优化，目前"有点生硬"**——优化方向：
- **学**：不只是"显示+播报"，而是**逐步引导**：先介绍键位规则（"数字键盘 7 对应点1，就是盲文左上角"），再演示一个例子，再让用户自己试
- **练**：有提示练习（"打出 a"），错误时给出**具体引导**（"a 是点1，按 7"）
- **考**：无提示考核 + 错题复习（间隔重复保留）
- **中文拼音**特殊：多阶段输入（声母→韵母→声调），用 `*`/`/` 切换阶段，学阶段逐个介绍每个方

### 5.1 中文拼音（全标调）
- 教："声母 m，韵母 a，**阴平**"（读标调名）
- 输入：`*` 下一个阶段、`/` 上一个阶段、0 提交判定
- 词汇：声母 18 + 韵母 34 + 声调 4

### 5.2 英文 26 字母
- 教："a = 按 7"（键位教学）
- 同 v3 学→练→考

### 5.3 符号（中英常用 10 个）
逗号、句号、问号、叹号、引号、括号、分号、冒号、省略号、顿号
（盲文符号点位：需查证，写入数据表）

### 5.4 数字
- 数字符号（点3456）+ a-j → 1-0
- 教："1 = 数字符号 + a"

## 6. AudioBraille 新功能测试（含展示环节）

### 6.1 展示环节（用户新建议：先展示再测试）
```
展示（首次进入必看）：
  1. 左列点 1/2/3：正弦波，左耳，600/400/250Hz 逐个播放
  2. 右列点 4/5/6：方波，右耳，600/400/250Hz 逐个播放
  3. 每个点播报「点1：左耳高音」… 听完按 0 进测试
```

### 6.2 测试
- **数字辨识**：随机播数字的 AudioBraille 编码 → 猜 → 反馈
- **26 字母辨识**：随机播字母 → 猜 → 反馈
- **拼音辨识**：按音节逐个蹦出（一个音节 = 声母方+韵母方+声调方）
- 反馈：错误直接说正确答案（字母/数字/音节），不读大数字

### 6.3 听书测试（用户确认）
- **可调倍速 AudioBraille 朗读**（1x~5x）
- 播放一段话/一篇文章，最后按钮问"**你是否能听懂？**"
- 作为新功能测试的一种方法

## 7. 笔记记录器增强

- 保留：盲文直出 + 明文对照 + 导出导入
- **新增朗读功能（用户建议）**，两种方法可调速度：
  1. **盲文转文字 → TTS 朗读**
  2. **直接 AudioBraille 朗读**（逐方播放）
- 速度可调（1x~5x）

## 8. 技术架构

- 纯前端 SPA，Vite + Vitest，模块化
- 模块：`braille-engine.js`（编码，唯一数据源）、`audio-braille.js`（AudioBraille 编码播放）、`input.js`（键盘输入，逐方确认）、`teaching.js`（四子模块）、`experiment.js`（音频测试）、`notes.js`（笔记+朗读）、`reader.js`（听书）、`speech.js`、`i18n.js`、`storage.js`
- 测试：单元测试 + 浏览器端到端验证
