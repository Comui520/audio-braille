## 1. 项目目标与用户定位

**一句话定位**：一个盲人友好的盲文教学平台，核心创新是 **AudioBraille 空间音频编码**（用声音"演奏"盲文点位），并用实验模式验证"声音转盲文"是否可行。

已确认的用户决策：

| 决策点 | 结论 |
|---|---|
| 目标用户 | **盲人为第一用户，所有功能盲人友好**；同时为明眼人提供合理设计（视觉点阵演示、协助调试） |
| 主要目的 | ① 教学现行盲文；② 测试 AudioBraille 声音编码可行性 |
| 声调 | **直接加入声调学习**（现行盲文完整声母+韵母+声调） |
| 输入反馈 | 点位切换发**极短咔嗒声**（低音量、无音高、可随时关闭）；完整 AudioBraille 和弦**仅在按 0 确认时**播放 |
| 输入方式 | **盲文为主**，严格遵循现行盲文规则 |
| 工程定位 | **正式工程 + 单元测试**（Vite + Vitest） |

## 2. 盲文编码规范（★ 后续实现必须遵守的核心数据）

> 本节为调查查证的权威结果，所有实现（映射表、解析、教学、测试）**必须**以此为准，不得臆造。

### 2.1 盲文基本结构

- 一方（cell）由 6 个点组成：左列自上而下为点 1、2、3；右列自上而下为点 4、5、6。
- 点位用数字串表示，如 `12` = 点1+点2。
- Unicode 显示：盲文 Unicode 块 U+2800~U+28FF。**U+2800 是空方**；有点的方 = `U+2800 + 位掩码`（点1=0x01、点2=0x02、点3=0x04、点4=0x08、点5=0x10、点6=0x20）。例：点1+2 → U+2803。

### 2.4 声调表

| 声调 | 汉语拼音 | 点位 |
|---|---|---|
| 阴平（1声） | ¯ | 点1 |
| 阳平（2声） | ´ | 点2 |
| 上声（3声） | ˇ | 点3 |
| 去声（4声） | ` | **点23**（不是点4！） |
| 轻声 | 无 | 不标调 |

### 2.5 变读规则

声母 g、k、h 与韵母 i、ü 以及与 i/ü 有关的韵母（i、ü、ia、ie、üe、iao、iu、ian、in、iang、ing、iong、üan、ün 等）相拼时，变读为 **j、q、x**。

例：g+iao → jiao；k+u → ku（不变）；h+ü → xu。

### 2.6 自成音节规则

- 声母 zh、ch、sh、r、z、c、s 可自成音节（书写时按其点位单独一方，相当于拼音 zhī/chī/shī/rì/zī/cī/sī 的音节）。
- 所有韵母可自成音节（书写时按韵母点位单独一方，如 a、o、e、yi、wu、yu）。

### 2.7 拼法规则

- 一个音节 = **声母方 + 韵母方（+ 声调方）**，各方独立，依次相拼。声母在左、韵母在右（相邻两方）。
- 以**词**为单位书写，词间空出一方。
- **标调**：
  - 现行盲文（1953）：原则不标调，需要时才标调（生僻词、成语、古汉语实词、专有名词首次出现、区分同声同韵词、单音节词等情形标调）。
  - 国家通用盲文（2018，本项目教学采用）：**全部音节标调**，同时按声母省写声调符号以减少篇幅：
    - f 声母开头的音节 → 省阴平符号
    - p、m、t、n、h、q、ch、r、c 声母开头 → 省阳平符号
    - b、d、l、g、k、j、x、zh、sh、z、s 声母开头 → 省去声符号
    - 无（零）声母的音节 → 省去声符号
    - 轻声、变调不标
  - 另有 3 种规避轻声的例外情形（实现教学模块时按附录规则处理）。

- GB/T 15720-2008《中国盲文》（国标，含现行盲文方案与汉语双拼盲文方案）
- 维基百科"现行盲文""国家通用盲文"条目

## 3. 系统架构

### 3.1 技术栈

- Vite（构建/开发服务器/热更新）+ Vitest（单元测试）
- 原生 ES Modules，无重型框架
- 纯前端 SPA，构建产物为静态文件，可离线部署（盲校无网环境）

### 3.2 模块划分

```
src/
  braille-engine.js    # 盲文编码核心：点位↔声母/韵母/声调/字母映射、变读、解析、候选词、U+2800
  audio-braille.js     # AudioBraille 空间音频编码与播放
  input.js             # 数字小键盘输入器：点位切换、功能键、候选词导航
  teaching.js          # 教学模块：探索/考试/间隔重复错题本
  notes.js             # 笔记记录器：明文+盲文点位序列存储、回放、快捷键
  experiment.js        # 实验模式：A/B 组对比测试与统计
  app.js               # 入口：导航、AppState、无障碍初始化、模块整合
  styles.css           # 黑底黄字大字号主题 + 可切换主题
  main.js              # 入口文件
tests/
  braille-engine.test.js   # 映射/变读/解析/候选词
  audio-braille.test.js    # 音频编码正确性（纯逻辑层可测）
  teaching.test.js         # 间隔重复算法、错题本进出
  experiment.test.js       # 实验统计与对比逻辑
```

### 3.3 数据流

```
用户键盘 → input.js → AppState.brailleDots → 实时点阵图 + 咔嗒声反馈
用户按0确认 → braille-engine 解析（声母方→韵母方→声调方）→ 候选词 → 上屏
           + playAudioBraille 和弦 + speak() TTS
教学/实验 → teaching.js / experiment.js → AppState.learningProgress / localStorage
笔记 → notes.js → localStorage（明文 + 盲文点位序列）
```

### 3.4 全局状态 AppState

- `currentPage`：当前页面（教学/输入器/实验/笔记）
- `brailleDots`：长度为 6 的布尔数组（点1~点6）
- `inputStage`：当前输入阶段（声母方 / 韵母方 / 声调方）
- `learningProgress`：学习进度（关卡、正确率）
- `notes`：笔记列表
- `settings`：提示音开关、静音模式、主题、字号

## 4. 盲文核心引擎（braille-engine.js）— 第 2 步修订

### 4.1 数据表（必须与第 2 节一致）

- `INITIALS`：声母 → 点位（18 个，含 g/j、k/q、h/x 共用）
- `FINALS`：韵母 → 点位（34 个）
- `TONES`：声调 → 点位（阴平 1、阳平 2、上声 3、去声 23）

### 4.2 核心函数

- `dotsToComponent(dotsArray)`：单方 → 声母/韵母/声调/英文字母（查表 + 歧义处理）
- `syllableToDots(initial, final, tone)`：音节 → 方序列 `[声母方, 韵母方, 声调方?]`
- `charToSyllable(char)`：汉字 → 带调拼音（声母+韵母+声调）
- `applyVariation(initial, final)`：g/k/h 变读 j/q/x 规则
- `getCandidates(syllable)`：按"声韵调"索引的候选词（词库见 4.3）
- `dotsToUnicode(dotsArray)`：点位 → U+2800 盲文字符（位掩码法，勿用纯 U+2800）

### 4.3 候选词词库

- 规模：1500~2500 常用字（《现代汉语常用字表》一二级字表子集），按"音节（声母+韵母+声调）"索引
- 100 个远远不够（普通话 400+ 音节）
- 初期可硬编码，预留从外部数据文件加载的接口

### 4.4 教学分级（衔接"直接加入声调"）

- **初级**：声母方 + 韵母方（无调，2 方）
- **进阶**：+ 声调方（全标调 3 方，国家通用盲文思路）
- 探索/考试模式按级别出题

## 5. 数字小键盘输入器（input.js）— 第 3 步修订

### 5.1 物理映射（官方布局，可自定义，存 localStorage）

| 键 | 点位 | 键 | 点位 |
|---|---|---|---|
| 7 | 点1 | 8 | 点4 |
| 4 | 点2 | 5 | 点5 |
| 1 | 点3 | 2 | 点6 |

### 5.2 交互逻辑

- 按 6 个点位键之一：切换 `AppState.brailleDots` 对应位（0↔1），更新点阵图，发**极短咔嗒声**（低音量无音高）。
- **必须 `preventDefault()`** 所有盲文小键盘键位，避免焦点在 textarea 时同时上屏数字。
- 输入过程中不播放任何和弦音效（和弦仅在按 0 确认时触发）。
- **教学模式下**点位切换的语音播报（"点X亮起/熄灭"）可关闭，避免 TTS 轰炸。

### 5.3 功能键

| 键 | 功能 |
|---|---|
| 0 | 确认/送字：当前方解析 → 进入下一输入阶段（声母方→韵母方→声调方→上屏）；上屏时播放 AudioBraille 和弦 + TTS |
| 3 | 退格（删最后字符或回退到上一输入阶段） |
| -（减号） | 一键清空当前点阵，语音提示"已清空" |
| +（加号） | 朗读当前点位 + 播放当前点阵的和弦预览 |
| .（句号） | 插入空格 |
| 9 / 6 | 候选词下翻 / 上翻 |
| 0（候选栏激活时） | 选定候选词上屏 |

### 5.4 候选词交互

输入声母方+韵母方（+声调方）后，底部弹出候选栏；9/6 切换高亮，0 确认选定。

## 6. AudioBraille 空间音频（audio-braille.js）— 第 4 步修订

### 6.1 编码规则（核心创新，硬编码）

| 维度 | 规则 |
|---|---|
| 空间定位 | 左列点（1,2,3）→ PannerNode 定位 -90°（左耳）；右列点（4,5,6）→ +90°（右耳） |
| 音高 | 上行（点1,4）= 600Hz；中行（点2,5）= 400Hz；下行（点3,6）= 250Hz |
| **波形区分（新增）** | 左列用正弦波，右列用方波（或三角波）——单声道/蓝牙设备下不依赖声像也能区分左右列 |

### 6.2 播放

- `playAudioBraille(dotsArray)`：遍历 6 点，有点的音符同时响起（0.25s 短促立体声和弦）
- 仅按 0 确认（或 + 预览）时触发
- 播放时屏幕点位视觉高亮闪烁，匹配听觉反馈

### 6.3 声调码的自洽性

声调点位（点1/点2/点3/点23）全部落在音高映射范围内（600/400/250Hz），声调方可用同一套 AudioBraille 编码"演奏"，无需额外规则。

## 7. 交互式教学模块（teaching.js）— 第 5 步修订

1. **探索模式**：中央显示当前字符，TTS 朗读；用户自由按点位键探索，系统实时反馈点位名称；按 0 核对对错并播报。
2. **考试模式**：TTS 播报题目（"请打出字母 B"），用户输入后按 0 提交，记录正确率。
3. **间隔重复错题本**：
   - localStorage 存每字符错误次数与上次错误时间
   - 错误次数 ≥ 2 → 加入错题本
   - 每 5 题强制插入 1 题错题，连续正确 3 次移出
   - 复习调度采用 SM-2 简化变体（算法与调度逻辑单独成函数，配单元测试）
4. **进度恢复**：页面 load 时自动从 localStorage 恢复，**不要拦截 Ctrl+R**（浏览器刷新快捷键）。
5. 出题范围按教学分级（初级无调 / 进阶带调）。

---

## 8. 笔记记录器（notes.js）— 第 6 步修订

- 多行 textarea，完全键盘可访问；盲文输入上屏到光标位置。
- **盲文原码存储**：每次保存同时存明文（"你好"）与盲文点位序列（[[1,2],[2,3],...]）。
- 快捷键：Ctrl+S 保存（时间戳命名）、Ctrl+O 历史列表（上下键选择、Enter 打开）、Ctrl+N 新建。
- **盲文回放**：历史笔记中按 + 键，朗读明文 + 用 `playAudioBraille` 逐个"演奏"盲文方（每方间隔 0.3s）。
- 全局快捷键需与屏幕阅读器（NVDA/JAWS）和浏览器快捷键避让。

---

## 9. 实验模式（experiment.js）— 第 6 步修订

- **前置条件**：B 组（AudioBraille）前必须确认用户已掌握编码，否则对比无意义。
- **呈现方式**：题目用**音频口播**呈现（"随机显示 10 个字母"对盲人不成立，改为 TTS 播报字母名）。
- **A/B 组**：A 组传统 TTS 直接朗读字母名；B 组播放 AudioBraille 空间音频但不显示文字。
- **实验设计**：交叉/随机组序消除顺序效应；记录每组总耗时与正确率；耗时口径定义为"从播放结束到作答"。
- **结果播报**：屏幕 + 语音播报对比（"语音组 10 秒，AudioBraille 组 12 秒"）。

## 10. 全局无障碍规范

- 所有交互元素原生支持键盘（Tab 导航），不依赖鼠标。
- 默认字号 ≥ 20px；默认黑底黄字高对比；**提供主题/字号切换**（不同视觉障碍需求不同）。
- 动态内容加 `aria-live="polite"`，TTS 播报控制节奏，避免信息轰炸。
- 首次键盘敲击 → `audioContext.resume()` + 极短静音缓冲解锁 Web Audio（规避自动播放策略），激活后播报"音频引擎已就绪"。
- `speak(text)` 封装 Web Speech API：rate=0.9、pitch=1、中文清晰发音。
- 页面加载后自动聚焦主内容区，播报"欢迎来到 AudioBraille 盲文学习平台"。
- **提示音开关**（咔嗒声可随时关闭，独立于 Ctrl+Shift+M 的 TTS 静音）；F1 帮助菜单语音列出所有快捷键；Ctrl+Shift+M 静音模式（关 TTS、保留 AudioBraille 和弦）。
