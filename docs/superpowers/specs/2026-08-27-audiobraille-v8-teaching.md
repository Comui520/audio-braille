# AudioBraille v8 教学结构重构设计

## 问题
1. **线性流程不合理**：现在"声母→韵母→带调"必须顺序学，学一半退出下次从头开始
2. **TTS 无法朗读拼音**：`speak("声母 b")` 会读成"声母 be"，韵母同理
3. **缺少进度保存**：用户无法"今天学 b，明天接着学 p"

## TTS 朗读策略

### 声母/韵母不直接读拼音
```javascript
// ❌ 旧：speak("声母 b")  → TTS 读成"声母 be"
// ✅ 新：
function speakInitial(char) {
  speak(`声母 ${char}，盲文是点 ${dotsDesc(INITIALS[char])}`)
  // 输出："声母 b，盲文是点 1、2"
}

function speakFinal(char) {
  speak(`韵母 ${char}，盲文是点 ${dotsDesc(FINALS[char])}`)
  // 输出："韵母 a，盲文是点 3、5"
}
```

### 音节可以直接读
```javascript
speak("音节 bā")  // TTS 可以读出带调拼音
```

## 导航流程

### 用户路径 1：从头学
1. 首页 → 点"中文拼音"
2. 拼音页 → 看到"单声母 3/21"，点"单声母"
3. 声母列表 → 点"b"（已学）或"f"（下一个未学）
4. 学习页 → 学/练/考 → 点"下一个"自动跳到"d"

### 用户路径 2：继续上次进度
1. 首页 → 点"中文拼音"
2. 拼音页 → 看到"单声母 3/21"进度条，点"继续学习"按钮
3. 直接跳到"f"（当前未学的第一个）

### 用户路径 3：随机挑选
1. 首页 → 点"英文字母"
2. 字母页 → 点"i-p"小节
3. 字母列表 → 点"m"
4. 学习页 → 学/练/考

## 实现步骤

### 阶段 1：数据与存储（1 个文件）
- `src/curriculum.js`：课程定义 + 进度管理
- 函数：`getCurriculum()`, `getProgress(id)`, `markLearned(id, item)`, `getNextItem(id)`

### 阶段 2：教学页面重构（3 个文件）
- `src/teaching-home.js`：首页四大卡片
- `src/teaching-category.js`：二级页（如"中文拼音"的三个小节 + 进度条）
- `src/teaching-item.js`：三级页（单项学习，如"声母 b"）

### 阶段 3：语音策略（1 个函数）
- `src/teaching-speech.js`：`speakItem(type, char)` 智能判断声母/韵母/音节

### 阶段 4：整合与测试
- 替换旧 `teaching.js` 的 `view()` 返回值
- 测试：进度保存、TTS 朗读、导航跳转

## 优势
1. ✅ **灵活学习路径**：可跳跃、可继续、可随机
2. ✅ **进度可视化**：卡片上直接显示"3/21 已学"
3. ✅ **TTS 友好**：声母/韵母用描述读，音节直接读
4. ✅ **符合真实教材**：参考《通用盲文基础》五大模块
5. ✅ **明确学习目标**：每次只学一个字符，完成即跳转
