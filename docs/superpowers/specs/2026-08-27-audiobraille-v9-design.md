# AudioBraille v9 产品与架构规格

日期：2026-08-27
状态：用户已批准

## 1. 产品定位

AudioBraille 是一个帮助明眼人学习盲文、同时让盲人可使用的前端平台。产品有两个清晰主线：

1. 学习盲文：中文拼音、英文字母、符号、数字，以及直接输入练习和笔记。
2. 测试新方法：用 AudioBraille 空间音频辨识盲文，并提供听书式连续播放作为实验场景。

AudioBraille 实验不是普通的“听书功能”，而是产品的创新测试项目。界面必须把“实验”单独作为主要入口，听书作为实验中的一个场景。

## 2. 顶层信息架构

固定顶栏只有四个主入口：

- 首页
- 学习盲文
- AudioBraille 实验
- 笔记

“使用说明”放在首页的紧凑折叠区，不占用顶层导航。

### 2.1 学习盲文

学习页内部使用标签切换：

- 教学
- 在线输入

教学采用四级选择，而不是线性声母→韵母→带调流程：

```text
学习盲文
  └─ 四个内容区域
      ├─ 中文拼音
      ├─ 英文字母
      ├─ 符号
      └─ 数字
          └─ 分类页：细项/小节 + 每项进度
              └─ 单项页：学 / 练 / 考
```

用户可以在任意层级进入任意项：

- 选择“中文拼音”后，可以选“声母”“韵母”“音节练习”。
- 选择小节后，可以直接点 `b`、`m`、`a` 或任意音节，不强迫从第一个开始。
- 已学状态和当前项按小节保存，第二天可继续，不会重置。
- 单项页提供上一个、下一个、返回小节、标记已学。

### 2.2 AudioBraille 实验

实验页内部使用标签切换：

- 听觉辨识
- 听书场景

听觉辨识流程：

1. 选择字母、音节、符号或数字模式。
2. 展示左右耳、波形和音高的对应关系。
3. 用户按 0 进入一轮题目。
4. 每题先按 0 听音频，再逐方输入；`*` 确认下一方，0 提交。
5. 反馈正确答案并记录结果。
6. 完成后提供“再来一轮”和“换模式”。

听书场景是 AudioBraille 的连续播放实验：使用用户输入的盲文内容或内置文本，以 0.5x~5x 播放；提供播放、停止、速度和播放进度，不使用普通 TTS 代替 AudioBraille。

### 2.3 笔记

笔记页包含：

- 盲文直出编辑区。
- 中文模式的带调拼音对照，英文模式的逐方字母对照。
- 保存、历史、导入、导出、新建。
- “文字朗读（TTS）”和“盲文音频回放”两个明确按钮。
- 音频回放按方顺序播放，不把多方数组作为一个和弦传入。

## 3. 教学内容与数据

权威点位仍只来自现有 `braille-engine.js` 与 `data/symbols.js`，不得在 UI 层重复编码。

每个教学项目统一为：

```js
{
  id: 'latin.a',
  category: 'latin',
  section: 'letters-a-h',
  type: 'letter',
  label: 'a',
  cells: [[1]],
  unicode: '⠁'
}
```

多方内容必须保留方边界：

- 拼音音节：声母方、韵母方、声调方。
- 数字：数字符号方、数字字母方。
- 多方标点：每方独立。

## 4. TTS 策略

Web Speech 对孤立拼音字母并不可靠，因此不把单个声母/韵母当英语字符直接朗读。

- 声母：中文描述 + 点位，例如“声母，界面文字是 b，点位一、二”。
- 韵母：中文描述 + 点位，例如“韵母，界面文字是 a，点位三、五”。
- 音节：读“音节”和声调名称，避免让 TTS 猜拼音发音，例如“音节 ba，第一声；三方”。
- 英文字母：使用“英文字母，a，点位一”的描述；不能只传裸 `a`。
- 数字和符号：读中文名称、数字本身和方数；键位使用分隔后的单个数字。
- 只有明确的用户操作或流程变化才播报。点位键只更新视觉/可访问反馈，不播报；页面卸载、模式切换和定时器取消时不得产生遗留语音。

## 5. 输入与导航状态

`app.js` 是唯一页面路由和事件协调者。页面模块只返回 DOM 或处理纯业务动作，不直接替换全局主容器。

```js
const state = {
  page: 'home',
  learningTab: 'teaching',
  experimentTab: 'recognition',
  teaching: { category: null, section: null, item: null, phase: 'learn' },
  input: { cells: [], currentDots: [] },
  language: 'zh',
  audioUnlocked: false
}
```

所有页面按钮使用 `data-action` 和可选数据属性，由一个根级 click 委托处理。导航不依赖按钮初始化时机，不使用 `pageViews` 缓存。

小键盘规则：

- 7/4/1/8/5/2 对应点 1/2/3/4/5/6，顺序无关。
- `*` 确认当前方并进入下一方。
- `/` 回到上一方。
- `0` 提交当前动作。
- `3` 清当前方或回退上一方。
- `-` 清空。
- `+` 朗读/重听。
- `.` 插入空格。
- 组合键（Ctrl/Alt/Meta）不拦截，浏览器刷新 Ctrl+R 不拦截。

启动门只在未解锁时注册捕获监听；按 0 后立即移除监听器，且该事件不得进入输入器。

## 6. UI 视觉规范

采用明亮、简洁、学习工具风格：

```css
--page: #f6f7f9;
--surface: #ffffff;
--surface-muted: #f0f2f5;
--text: #20242a;
--text-muted: #5f6875;
--line: #d9dee6;
--brand: #2457c5;
--brand-hover: #19469f;
--success: #177245;
--danger: #b42318;
```

不使用深蓝紫主色、紫色渐变、霓虹发光、背景光晕或大面积装饰图形。颜色只用于层级、状态和操作反馈。

布局规则：

- 页面背景铺满视口，内容使用宽松的两栏/网格布局，不在页面外包“卡片套卡片”。
- 顶栏简洁固定，高度稳定；移动端导航折叠为水平可滚动标签，不把每个导航按钮堆成 800px 高的竖栏。
- 首页在常见桌面视口一屏完成：一句定位、折叠说明、四个入口。
- 教学分类页用内容网格；单项页采用“信息区 + 点阵区 + 操作区”的三段式。
- 内容超过视口时允许自然滚动；目标是减少不必要的滚动，不以 `overflow: hidden` 隐藏内容。
- 所有按钮有明确边框、hover、active、focus-visible、disabled 状态。
- 盲文方点阵使用真实命名 grid areas，点位顺序明确为 1/4、2/5、3/6。
- 文本和控件符合 WCAG AA 对比度；正文不少于 16px；不依赖颜色单独表达状态。

## 7. 错误与生命周期

- 所有异步播放有停止标志，换页时停止。
- 教学和实验的展示定时器集中管理，换页/换模式/重新开始时清理。
- TTS 封装提供 `cancelSpeech()`，页面切换时调用；正常播报仍会取消前一句，避免语音堆积。
- 缺失点位、空输入、损坏导入文件显示可见错误，并只播报一次。
- localStorage/IndexedDB 只经 `storage.js` 访问；课程进度使用 `storage.saveProgress/loadProgress`。

## 8. 验收标准

1. 首页四个主入口在鼠标点击和键盘 Enter 下都能一次进入。
2. 顶栏只显示：首页、学习盲文、AudioBraille 实验、笔记。
3. 学习页可在教学/在线输入之间切换；教学页可自由选择四个区域、细项和单个项目。
4. 学习进度刷新页面后仍在，切换项目不会回到第一个项目。
5. 拼音声母/韵母的 TTS 不依赖裸拼音发音；视觉文字保留拼音。
6. 单项教学能显示字符、Unicode 盲文、真实六点点阵、点位和键位。
7. AudioBraille 实验的多方题逐方播放、逐方提交，完成后能再来一轮。
8. 笔记的两个朗读按钮语义清楚：一个 TTS，一个 AudioBraille。
9. 页面切换不会触发旧页面语音或旧定时器。
10. `npx vitest run`、`npm run build` 和 Playwright 桌面/移动端走查通过。
